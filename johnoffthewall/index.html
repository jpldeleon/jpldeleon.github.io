Project Overview

John Off the Wall is a responsive personal website built as Capstone Project 2 for Angela Yu's Complete Full-Stack Web Development Bootcamp. Designed using semantic HTML5 structure and clean CSS3 styling, the site showcases personal background details, technical projects, creative hobbies, and a dedicated contact section across all screen sizes. practices.

Problem & Objective

The goal of this capstone project was to create an original, custom-designed personal website from scratch without using step-by-step solution code or video walkthroughs. It focuses on organizing semantic page layouts, establishing clean site navigation, applying responsive CSS rules, and ensuring full accessibility.

Technical Implementation

The application is structured around semantic HTML5 tags (`header`, `nav`, `section`, `footer`) to prioritize document accessibility and clear navigation. CSS properties and responsive layout principles, including flexbox and media queries, ensure the website adapts seamlessly across mobile, tablet, and desktop viewports.

Implemented Features

Dynamic Light / Dark Theme Toggle

Client-side theme switching with CSS variables, keyframe rotation feedback, and LocalStorage state persistence.

Interactive Lightbox Dialogs

Integration with GLightbox for interactive media pop-ups, complete with touch-gesture support and custom button alignment scripting.

Fully Responsive Layout

Built using Bootstrap 5 flexible grids and custom media queries to provide a continuous view across desktop, tablet, and mobile displays.

Semantic Codebase & Fallbacks

HTML5 semantic structure paired with dynamic DOM error handling to render SVG placeholders for unlocated assets.

Key Outcome & Takeaways

This project demonstrates clean web design execution, semantic document structuring, and responsive CSS layout techniques. Building modular stylesheet rules and responsive media queries provides a solid foundation for structured, scalable web design.
