Project Overview

John Off the Wall is a responsive personal website built as Capstone Project 2 for Angela Yu's Complete Full-Stack Web Development Bootcamp. Built with semantic HTML5 structure and clean CSS3 styling, the site showcases personal background details, technical projects, creative hobbies, and a dedicated contact section optimized across all device viewports.

Problem & Objective

The core objective of this capstone project was to design and build an original personal portfolio site from scratch, without relying on solution code or step-by-step video tutorials. The project focused on structuring semantic page layouts, organizing clear site navigation, crafting custom responsive CSS layouts, and adhering to web accessibility best practices.

Key Outcome & Takeaways

This project provided essential hands-on experience in modern front-end web design, semantic document structuring, and responsive CSS architecture. Building custom utility scripts and modular stylesheet rules laid a solid, practical foundation for designing accessible and scalable web interfaces.

Technical Implementation

The site's architecture is centered on semantic HTML5 elements—such as header, nav, section, and footer—to maintain accessible document outline hierarchy and intuitive navigation. On the styling layer, custom CSS layout techniques like Flexbox, CSS Grid, CSS variables, and fluid media queries ensure the layout adapts smoothly across mobile, tablet, and desktop viewports.

Throughout development, I used Claude (Anthropic's AI assistant) as a virtual pair programmer and technical learning partner. Working through my first custom client-side features, I consulted Claude to debug DOM manipulation logic, structure clean LocalStorage key-value handling for theme persistence, and evaluate fallback behaviors for missing image assets. This collaborative workflow helped me build a deeper practical understanding of vanilla JavaScript and front-end state management while ensuring I authored and understood every line of CSS and JavaScript.

Implemented Features

Dynamic Light / Dark Theme Toggle

Client-side theme switching engineered with CSS custom properties, keyframe rotation feedback, and LocalStorage state persistence.

Interactive Lightbox Dialogs

Integration with GLightbox for interactive media pop-ups, featuring touch-gesture support and custom button alignment scripting.

Fully Responsive Layout

Built using Bootstrap 5 flexible grids and custom media queries to provide a continuous, fluid presentation across all screen sizes.

Semantic Structure & Asset Fallbacks

Semantic HTML5 document architecture paired with dynamic DOM error handling to render fallback SVG placeholders for unlocated image assets.
