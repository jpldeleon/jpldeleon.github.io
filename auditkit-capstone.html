Project Overview

AuditKit is a lightweight web tool built as a capstone project for Angela Yu’s Complete Full-Stack Web Development Bootcamp. It helps automate quick technical SEO checks by fetching on-page metadata, parsing page structure, and displaying basic performance metrics in a single view.

Problem & Objective

Checking basic SEO elements across different tools can take unnecessary time. The goal of this project was to build a simple, single-page dashboard that fetches and displays essential technical data automatically.

Technical Implementation

The application runs on a simple Node.js and Express.js server that processes user URL inputs and manages server-side logic. When a user submits a URL, Axios sends HTTP requests to the Google PageSpeed Insights API to retrieve mobile and desktop performance benchmarks. At the same time, Cheerio parses the raw HTML document to extract essential on-page SEO signals, including title tags, meta descriptions, heading structures, and Open Graph data. The parsed data and API responses are then passed into EJS templates to dynamically render a clean, readable audit report for the user.

Implemented Features

On-Page SEO Extraction

Automated server-side extraction of title tags, meta descriptions, open graph tags, and heading structures using Cheerio.

Core Web Vitals Auditing

Direct integration with Google PageSpeed Insights API to fetch live desktop and mobile performance metrics via Axios.

Server-Side Processing

Asynchronous request handling, error management, and HTML parsing built using Node.js and Express.js.

Clean UI & Reporting

Dynamic presentation of parsed audit data rendered cleanly with EJS templates and responsive CSS.

Key Outcome & Takeaways

This project demonstrates how to build a functional, server-side web application that solves a real SEO workflow problem. By combining public API integration, HTML parsing, and clean templating, AuditKit provides a fast way to evaluate core technical SEO factors in one place.
