Project Overview

AuditKit is a lightweight web application built as my capstone project for Angela Yu’s Complete Full-Stack Web Development Bootcamp. It automates quick technical SEO checks by fetching on-page metadata, parsing DOM structure, and presenting core performance metrics in a single, accessible dashboard.

Problem & Objective

Manually auditing basic technical SEO factors across multiple individual tools can be time-consuming. My goal for this project was to build a streamlined, single-page application that accepts a target URL, executes the necessary requests behind the scenes, and automatically generates an easy-to-read audit summary.

Key Outcome & Takeaways

This project provided valuable, hands-on experience in building a functional full-stack application that addresses a real-world web workflow problem. Combining third-party API integration, DOM scraping, and server-side templating strengthened my understanding of asynchronous JavaScript, HTTP response handling, and full-stack application structure.

Technical Implementation

The application runs on a Node.js and Express.js server responsible for processing user inputs and handling server-side logic. When a user submits a URL, Axios handles asynchronous HTTP requests to the Google PageSpeed Insights API to retrieve mobile and desktop performance benchmarks. Concurrently, Cheerio parses the target site's raw HTML document to extract essential on-page SEO signals, including title tags, meta descriptions, heading hierarchies (H1–H6), and Open Graph meta tags. The backend formats this aggregated data and passes it into EJS templates to dynamically render the final audit report.

As an entry-level developer navigating complex server-side operations, I integrated Claude (Anthropic's AI assistant) into my development workflow as a virtual pair programmer. I utilized Claude primarily to debug asynchronous request flows, refine Cheerio selector logic, review error-handling structures for invalid URLs, and talk through backend edge cases. This interactive troubleshooting approach helped me deepen my practical understanding of Node.js, API data extraction, and server-side rendering while ensuring I understood the underlying logic of every route and function.

Implemented Features

On-Page SEO Extraction

Automated server-side parsing of title tags, meta descriptions, Open Graph data, and heading structures using Cheerio.

Core Web Vitals Auditing

Direct integration with the Google PageSpeed Insights API via Axios to fetch live desktop and mobile performance metrics.

Server-Side Processing

Asynchronous HTTP request handling, robust error management, and HTML data parsing built using Node.js and Express.js.

Clean UI & Reporting

Dynamic presentation of audit results rendered cleanly using EJS templates and responsive CSS layout techniques.
