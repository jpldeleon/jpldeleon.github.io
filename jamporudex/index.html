Project Overview

JamporuDEX is my Capstone Project for Angela Yu's Full-Stack Web Development Bootcamp. Inspired by Derek Sivers' book notes site (a key reference in the capstone prompt), I built a personal web app to track anime and manga. Users can search for titles, auto-fetch cover art from MyAnimeList, and save entries to a custom dashboard with status updates, episode or chapter progress, star ratings, and short reviews. The app features dynamic sorting and filtering, backed by full persistence through a PostgreSQL database so data stays intact across server restarts.

As an anime fan, I wanted to build a practical tool tailored to my actual hobbies rather than another standard to-do list tutorial. Working on a project I genuinely enjoyed using kept me motivated and engaged through every step of development.

To help with the development process, I used Claude (Anthropic's AI assistant) to debug tricky errors, review my code, and talk through complex features like external API fallback logic. Working alongside AI provided fast guidance similar to checking developer forums or official documentation. While leveraging these tools for technical support, I designed the database schema, wrote the Express route handlers, and structured the core backend logic myself to make sure I truly understood how every piece operated.

Problem & Objective

The main objective of this capstone was to design and build a full-stack CRUD application from scratch, using PostgreSQL for persistent storage and integrating an external public API without starter templates. This required designing a relational database schema, setting up RESTful Express routes, and managing data flow between PostgreSQL, the Node backend, and EJS template views. As an entry-level developer, my main focus was building a strong grasp of core backend fundamentals, understanding request-response lifecycles, and improving my step-by-step debugging skills.

Key Outcome & Takeaways

This was my first time connecting a live relational database to a backend server instead of using temporary in-memory data. It forced me to think through my database schema before writing backend routes. Integrating the Jikan API was another great learning experience; I didn't expect a free public API to time out so often, so building retry loops and an AniList fallback was an unexpected challenge that became one of the parts I'm most proud of.

I ran into plenty of bugs along the way, and using Claude to talk through why errors were happening helped me learn the root causes rather than just pasting quick fixes. As an entry-level developer, this project gave me real confidence in my ability to explain and defend every line of code I shipped.

Technical Implementation

The backend is built with Express.js and connects to PostgreSQL using the pg library. A media_entries table manages persistent data storage for items like MAL IDs, titles, status, progress metrics, ratings, reviews, synopses, and image URLs. External data fetching relies on Axios to query the Jikan API (a public MyAnimeList wrapper) for metadata and cover images. To handle rate limits and temporary service outages, the backend includes exponential backoff retry logic and an automated fallback to the AniList GraphQL API to keep search reliable.

The application uses EJS for server-side template rendering, paired with plain JavaScript on the frontend to power search modal popups, entry editing, server-side dynamic sorting and filtering, and theme switching without extra frontend frameworks.

Implemented Features

Full CRUD with PostgreSQL

Add, view, edit, and delete entries using Express routes and parameterized SQL queries connected to a real PostgreSQL database so your index persists across sessions.

Jikan API Search with AniList Fallback

Search MyAnimeList via the Jikan API directly inside the modal to pull cover art and synopses. If Jikan times out, the server retries and falls back to AniList automatically.

Sort & Status Filter

Sort entries by rating, date added, or title, and filter lists by reading or watching status using query parameters processed on the server.

Dark Theme Toggle

Switch between dark theme styles (Tokyo Night Storm and Dracula) using CSS variables and localStorage to save user preferences across page navigation.
